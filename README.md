# ESPU AI Launcher privacy

Public privacy policy for ESPU AI Launcher: Calm &amp; Smart.

The published policy covers ESPU AI Launcher 2.2 (version code 16), including selected-file OCR and bounded SDK diagnostics, ESPU's on-device Action Model and opt-in private suggestion adapters, ESPU Island and optional default-Phone controls, missed-call follow-up and local voicemail transcription, read-only Calendar Agenda, encrypted Personal Archive, live weather, Android widgets, and current privacy safeguards. The policy page is maintained in `index.html` for GitHub Pages and Google Play disclosure use.
