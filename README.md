# ESPU Launcher: Home Studio privacy

Public privacy policy for ESPU Launcher: Home Studio. Official product site: [espulauncher.com](https://espulauncher.com).

The published policy covers ESPU 3.4, version code 36, as an unrestricted Production candidate. ESPU 3.0/version code 30 remains the same-certificate upgrade baseline only. It documents Home Studio, six bundled corporate themes, eight All Apps presentations, widgets, Notes, Calendar, Focus, Universal Search, selected-file OCR and transcription, the typed on-device ESPU Control action model, the reviewed Google Gemini foreground handoff, and optional default-Phone/ESPU Island functionality including bounded read-only Recents.

ESPU has no advertising SDK, ESPU account, subscription system, or ESPU-operated behavioral analytics. Integrated live weather, External Brain, Android Auto/ESPU Drive, and ESPU-owned live microphone recognition are retired. Tapping Voice opens Google Gemini in the foreground; ESPU requests no microphone permission and does not receive Gemini conversations. The policy page is maintained in `index.html` for GitHub Pages and Google Play disclosure use; it documents candidate behavior but does not represent Google Play approval or production rollout authorization.
