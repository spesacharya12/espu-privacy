# ESPU Launcher: Home Studio privacy

Public privacy policy for ESPU Launcher: Home Studio.

The published policy covers the ESPU 3.1 version-code-31 unrestricted Production candidate. ESPU 3.0/version code 30 remains the same-certificate upgrade baseline only. The policy documents the on-device ESPU Control action model, optional default-Phone experience, ESPU Island, ESPU Deck, Home Studio, widgets, Notes, Calendar, Focus, Universal Search, selected-file OCR, offline Vosk voice recognition, reviewed Android assistant handoffs, permissions, retention, and user-controlled deletion.

Integrated ESPU live weather and Google Play Asset Delivery are retired in this candidate. The signed base install contains the approved theme, wallpaper, and offline voice assets. The policy page is maintained in `index.html` for GitHub Pages and Google Play disclosure use; it documents candidate behavior but does not represent Google Play approval or production rollout authorization.
