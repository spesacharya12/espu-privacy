# ESPU AI Launcher privacy

Public privacy policy for ESPU AI Launcher: Calm &amp; Smart.

The published policy covers ESPU AI Launcher 2.1 (version code 15), including ESPU's on-device Action Model, opt-in local learning, Intent Inbox drafts, ESPU Island, the optional default-Phone experience, dual-SIM account selection, on-device call-history controls, live weather, Android widgets, and current privacy safeguards. The policy page is maintained in `index.html` for GitHub Pages and Google Play disclosure use.
