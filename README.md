# ESPU AI Launcher privacy

Public privacy policy for ESPU AI Launcher: Calm &amp; Smart.

The published policy covers the ESPU AI Launcher 2.4 (version code 21) QA closed-testing candidate, including ESPU Deck's local typing and explicit selected-text handoff, on-device Contacts search indexing, optional Usage Access screen-time summaries, selected-file OCR and bounded SDK diagnostics, ESPU's deterministic on-device Action Model and private suggestion adapters, reviewed `ACTION_DIAL` handoffs that never make ESPU a Phone or Assistant handler, live-weather evaluation, and Google Play Asset Delivery for wallpaper, Theme Pack, and Offline Voice content. The policy page is maintained in `index.html` for GitHub Pages and Google Play disclosure use; it does not authorize production promotion.
