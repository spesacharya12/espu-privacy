# ESPU AI Launcher privacy

Public privacy policy for ESPU AI Launcher: Calm &amp; Smart.

The published policy covers the ESPU AI Launcher 2.3 (version code 18) closed-testing candidate, including on-device Contacts search indexing, optional Usage Access screen-time summaries, selected-file OCR and bounded SDK diagnostics, ESPU's on-device Action Model and private suggestion adapters, optional default-Phone controls, live-weather evaluation, and Google Play Asset Delivery for wallpaper, Theme Pack, and Offline Voice content. The policy page is maintained in `index.html` for GitHub Pages and Google Play disclosure use; it does not authorize production promotion.
